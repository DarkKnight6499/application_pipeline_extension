# Fixture policy

- Fixtures are hand-built HTML that reproduce the structure seen in an Inspect-only export.
- Never paste raw employer HTML into the repository.
- Replace every label that could carry personal data with neutral text.
- All values use `example.invalid`.
- Record the export a fixture came from by date and page key only.
- Fixtures contain no real candidate data, tenant identifiers, or tracking tokens.
